## How to Run
1. Keep `Number guessing game.py` and `01.ico` in the **same folder**
    - Since I'm using tkinter, the app needs `01.ico` in its working directory to run, otherwise it'll throw an error since it can't find the icon file.
2. Run the script with Python:
   ```bash
   python "Number guessing game.py"
